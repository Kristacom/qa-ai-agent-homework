# Skill: Test Design

## Purpose
Проектирование тестовой модели на основе проанализированных требований.
Skill предназначен для создания структурированных тестовых сценариев (тест-кейсов), обеспечивающих полное покрытие функциональности, включая позитивные, негативные и граничные сценарии, для последующего экспорта в Test IT.

## Inputs
- Проанализированные требования (прошедшие Quality Gate)
- Критерии приемки
- Бизнес-правила и ограничения
- Указание на проект в Test IT

## Procedure
При проектировании тестовой модели необходимо:
1. Определить позитивные сценарии (Happy path) — проверка успешного выполнения функциональности с валидными данными.
2. Определить негативные сценарии — проверка поведения системы при невалидных данных, ошибках или недопустимых действиях.
3. Определить граничные значения (Boundary values) — проверка крайних допустимых значений (например, минимальная/максимальная длина строки, нулевые значения).
4. Сформировать шаги выполнения для каждого сценария (Preconditions, Steps, Expected Result).
5. Связать каждый тест-кейс с исходным требованием и задачей в Jira.

## Rules
При выполнении проектирования тестов необходимо соблюдать следующие правила:
- не создавать тест-кейсы без связи с требованиями
- не дублировать проверки (избегать избыточности)
- обязательно покрывать негативные сценарии и граничные значения
- каждый тест-кейс должен иметь предусловия (Preconditions), шаги и ожидаемый результат
- не изменять требования и не додумывать функциональность, которой нет в требованиях

## Output
Результат выполнения Skill должен содержать:
- Структурированный список тест-кейсов (артефакт `TestModel`), готовый для импорта в Test IT.
- Для каждого тест-кейса: название, тип (позитивный/негативный/граничный), предусловия, шаги, ожидаемый результат, ссылка на требование.

## Completion Criteria
Skill считается успешно выполненным, если:
- Все требования имеют соответствующее тестовое покрытие
- В тестовой модели присутствуют позитивные, негативные сценарии и граничные значения
- Каждый тест-кейс содержит шаги и ожидаемый результат
- Установлены связи между тест-кейсами и требованиями
